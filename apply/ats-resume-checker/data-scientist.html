Three fixes that matter for data scientists and AI/ML engineers

  • Say what you built, then what it changed. “Built a churn model in Python that the retention team used to pick which accounts to call” beats a list of libraries.
  • Use the exact words for GenAI work. LLMs, Generative AI and RAG each appear in a large share of these postings. If you built a RAG pipeline or fine-tuned a model, write those words; “worked on AI” matches nothing a recruiter types.
  • Show how you measured it. The metric, the baseline and the result on data the model had not seen. Interviewers ask about this first.

Add a skill to your CV only if you have used it. A recruiter will ask about every line.
